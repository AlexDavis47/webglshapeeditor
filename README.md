# WebGL Shape Editor
## An obscure "model" editor for basic 2D WebGL graphics.
In my university work, I had multiple projects which required WebGL 2D model definitions, in embedded JS arrays.
This project was created as a tool to reduce the amount of time I had to spend defining every vertice and color manually.
It likely has no use to anybody.

### Features:
* Graphically add, remove, and edit the positions and colors of individual vertices
* Sidebar UI allowing manual configuration of the program behavior and selected vertice
* Layer system allowing composition of larger pictures using simple shapes
* Support of (all?) WebGL render modes
* Export of models into js files
* Simple copy and paste of positional and color data
* Configurable snapping
